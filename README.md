# moyu-codex-install

Codex 桌面应用一键管理工具 — 自动检测、卸载、重装与数据迁移，支持交互式引导，适用于任意 Windows 设备。

## 文档说明

本仓库包含可执行文档，供 WorkBuddy / QoderWork AI 助手在 Windows 设备上自动执行：

| 文档 | 用途 | 适用场景 |
|------|------|---------|
| `Codex通用管理指南.md` | 通用版，支持交互流程 | 任意 Windows 设备，支持检测/安装/卸载/迁移全流程 |

## 功能覆盖

- **自动检测**：扫描 UWP（商店版）和 Win32 两种安装方式
- **彻底卸载**：文件系统 / 注册表 / 计划任务 / 服务 / 环境变量 五维度无残留验证
- **干净重装**：从官方页面下载安装，自动验证安装结果
- **数据迁移**：通过 junction 将 C 盘数据目录迁移到任意磁盘（默认 `D:\Codex\WorkSpace`）
- **配置更新**：自动写入 HTTPS 轮询模式（`model_provider = "openai_https"`）
- **一键回滚**：迁移失败时可恢复 C 盘原始路径

## 使用方式

将对应文档发送给 WorkBuddy / QoderWork，AI 助手会按文档步骤自动执行操作，并在关键节点暂停等待用户确认。

## 注意事项

- `Documents\Codex`（项目工作空间）不支持 junction 迁移，必须保留在 C 盘
- 路径中含 `&` 等特殊字符时需用 PowerShell 操作
- 迁移前必须关闭 Codex 进程
